# Keyboard and mouse

The window's shortcuts can be changed in **Settings ▸ Shortcuts**. Every command, with or without a shortcut, can be
run from the command palette.

## General

| Shortcut | Command |
|---|---|
| `Ctrl+Shift+P`, `F1` | Command palette |
| `Ctrl+S` | Save |
| `Ctrl+Alt+S` | Save all |
| `Ctrl+E` | Export |
| `Ctrl+B` | Build |
| `F5` | Refresh: take in changes made outside the editor |
| `F11` | Full screen |
| `Delete` | Delete what is selected: an asset, a step of a stack, a box of a graph |

## Undo

| Shortcut | Command |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Redo |
| `Ctrl+Alt+Z` | Undo in the project |
| `Ctrl+Alt+Shift+Z` | Redo in the project |
| `F`, over the History pane | Flip between an earlier moment and now |

## Moving around

| Shortcut | Command |
|---|---|
| `Alt+←`, mouse back button | Back |
| `Alt+→`, mouse forward button | Forward |
| `Alt+↑` | Up a folder |
| `Ctrl+W` | Close tab |
| Middle-click a tab | Close it |
| `Ctrl+Page Down`, `Ctrl+Page Up` | Next tab, previous tab |
| `Ctrl+Space` | Documents only |
| `Ctrl +`, `Ctrl −`, `Ctrl 0` | Zoom in, zoom out, actual size |

## Documents

| Shortcut | Command |
|---|---|
| `Ctrl+1` | Show as Preview |
| `Ctrl+2` | Show as Files |
| `Ctrl+3` | Show as Graph |

## In views

These are part of each view, and cannot be changed.

**Pictures and graphs**

| Input | What it does |
|---|---|
| Mouse wheel | Zoom |
| Drag empty space | Pan |
| Double-click | Fit |
| `Home` | Fit the graph |

**3D view**

| Input | What it does |
|---|---|
| Middle drag | Orbit |
| `Shift` + middle drag | Pan |
| Mouse wheel, `Ctrl` + middle drag | Zoom |
| Numpad `1`, `3`, `7` | Look along an axis |
| Numpad `5` | Perspective or orthographic |
| `Home`, `.` | Frame everything, frame the selection |
| `Space`, `←`, `→` | Play a clip, step a frame |

**Sound timeline**

| Input | What it does |
|---|---|
| `Space` | Play or pause |
| `Home` | Go to the start |
| Mouse wheel | Zoom |
| `Delete` | Remove the selected note |
