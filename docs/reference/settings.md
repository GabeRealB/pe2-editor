# Settings

Open the settings with **Edit ▸ Settings…**. On the left are your own settings, which apply to every project on
this computer, and below them the open project's.

## Your settings

| Page | What it sets |
|---|---|
| **Appearance** | Light or dark **Theme** and the **Accent color**; the default **Upscaling** of pictures; the **Zoom**, or following the monitor; and the performance overlay, which shows what the editor costs over the window. |
| **External tools** | Which program opens each kind of file. See [Importing and exporting](../working/import-export.md#opening-in-another-program). |
| **Files** | How the project folder is made available to other programs, and when changes made outside the editor are taken in: when you come back to the editor, or as they happen. |
| **Startup** | Whether the last project opens again when the editor starts. On Linux, which display system the window uses. |
| **Shortcuts** | The keys and mouse buttons that run each command. Click one and press the new key; **Default** puts it back. |
| **Agents** | Whether AI agents may use the editor's window. See [AI agents](../extending/agents.md). |
| **Licenses** | What the editor is built with, and under which licenses. See [Licenses](licenses.md). |

The bottom of each page says where your settings are saved.

## The project's settings

| Page | What it shows |
|---|---|
| **General** | The generated layers and how far they are filled, and where your discs are read from. |
| **Releases** | The discs each release of the game needs, and whether they are found. |
| **Layers and mounts** | The project's layers, bottom to top, and folders brought into it from elsewhere. |
| **Configurations** | The ways the project can be built, and their properties, to set. See [Configurations](../making/configurations.md). |

The project's settings belong to the project and are shared with everyone who uses it. Where your discs are, and
which configuration you work in, are kept for you on this computer only.

Extensions have settings of their own, in the **Extensions** pane. See [Extensions](../extending/extensions.md).
