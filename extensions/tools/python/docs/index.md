# pe2.python

CPython 3.14.10, every module of its standard library that needs nothing outside CPython built in, as the editor's releases build it (MSYS2's CPython for MinGW on Windows).

It offers these programs, which a project's operations and other extensions start as `pe2.python:<program>`:

| Program | What it is |
|---|---|
| `python3` | the interpreter |

It runs outside the sandbox, as what offers programs does, and fetches what it offers once the project trusts it.
